# NHANES-Data-Analysis
Capstone project exploring NHANES body measurements using Python, NumPy , and data visualisation

Project Overview

This capstone project explores adult male and female body measurements using Python and numerical data analysis. It uses NHANES-related datasets to compare weight distributions, calculate BMI, study correlations, and examine waist-based ratios.

Objectives

- Load and analyse multidimensional data using NumPy.
- Compare male and female weight distributions using histograms and boxplots.
- Calculate BMI and standardise measurements.
- Examine Pearson and Spearman correlations.
- Calculate waist-to-height and waist-to-hip ratios.
- Interpret results using statistical summaries and visualisations.

Tools and Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

Project File

"Capstone_Project_1_NHANES (2).ipynb"

The notebook contains the code, visualisations, statistical analysis, interpretations, and references.

Key Learning Outcomes

This project provided practical experience in data cleaning, numerical computation, statistical analysis, data visualisation, and interpreting relationships between body measurements.
